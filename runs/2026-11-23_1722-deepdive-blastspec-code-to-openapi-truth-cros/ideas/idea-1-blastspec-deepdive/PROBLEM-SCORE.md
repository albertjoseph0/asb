# Problem Score — BlastSpec — Code-to-OpenAPI Truth & Cross-Repo SDK Blast-Radius CI Gate

## Scenario A
- **Buyer:** Engineering leads and backend maintainers at 2-30 engineer API-first SaaS companies shipping REST/OpenAPI APIs in FastAPI, Express/Hono/Next.js, Go, or Rails whose APIs are consumed by multiple internal repositories, external partner integrations, or generated TypeScript/Python/Go client SDKs.
- **Problem:** Preventing backend route changes (including AI-coded PRs) from drifting out of sync with openapi.yaml and silently breaking downstream internal consumer repos, external partner integrations, or generated client SDKs (including non-wire operationId/component renames) without maintaining Pact brokers or custom AST scripts — framed around the 2026 Optic archival, Stainless hosted shutdown, and Postman Free 1-user cap.
- **Trade-offs:** Strictly code-to-OpenAPI truth extraction plus cross-repo consumer/SDK blast-radius CI gating: no hosted API docs portal, no Postman-style manual API client UI, no hosted SDK code-gen runtime; supports 4 framework families first (FastAPI, Express/Hono/Next.js, Go, Rails — no SOAP/gRPC/legacy ESBs); requires GitHub/GitLab read-only App installation across both API provider and downstream consumer repositories.
- **Price:** $99/mo flat per GitHub/GitLab org (up to 5 API services, 15 consumer repos, unlimited seats) and $249/mo (20 API services, unlimited consumer repos, stainless.yml migration importer) (More for More)
