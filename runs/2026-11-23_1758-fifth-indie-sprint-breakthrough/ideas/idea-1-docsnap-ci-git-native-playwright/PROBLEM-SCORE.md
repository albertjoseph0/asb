# Problem Score — DocSnap CI — Git-Native Playwright Visual Sync for B2B SaaS Help Docs

ID: `IDEA-1` · Ambition: `indie` · Active Scenario: `Scenario A` · Signals: SIG-10, SIG-13

## Target Market (Scenario A)
- **Buyer:** Engineering leads, product managers, and technical writers at 5-100 person B2B SaaS companies shipping web UI changes at least biweekly whose customer help center runs on Git-backed MDX (Docusaurus, Fumadocs, Astro Starlight, Mintlify) or Zendesk/Intercom/Help Scout.
- **Problem:** Frequent UI releases silently break help-center screenshots and step guides at fast-shipping B2B SaaS companies, forcing manual re-capture or fragile DIY Playwright scripts; proposed solution compiles deterministic, PII-masked, selector-annotated light/dark screenshots via a Git-native Playwright CI Action opening visual-diff PRs or syncing to Zendesk/Intercom/Help Scout.
- **Trade-offs:** No Chrome-extension click recorder for non-technical HR/ops teams (strictly Git-checked declarative Playwright/YAML); never hosts or replaces the help center (no CMS, search, or chatbot—only visual asset PRs and media API syncs); headless Linux Chromium against web staging/preview URLs only (no native iOS/Android or desktop binary capture).
- **Price:** $99/mo flat per product (up to 300 auto-refreshed annotated shots, light+dark variants, unlimited seats/PRs) or $179/mo (up to 1,000 shots) (More for Less)

## Scenario B — Narrowed Niche
- **Buyer:** Localization, docs-ops, and engineering leads at 50-250 person international B2B SaaS companies shipping web UI changes at least biweekly who maintain active customer help centers in 5+ languages (e.g., EN/ES/DE/FR/JA/PT) on Git-backed MDX or Zendesk/Intercom paired with a TMS (Lokalise, Crowdin, or Phrase).
- **Problem:** Every biweekly UI release multiplies screenshot rot across 5-15 localized help-center languages (500-3,000+ localized images), forcing costly translation-agency DTP graphic rework ($40-$85/hr) or per-locale SaaS capture overages across CJK/RTL fonts, locale formatting, and translated callout annotations.
- **Trade-offs:** Strictly declarative Git-checked Playwright/YAML locale-matrix runs (no Chrome-extension click recorder for non-technical support teams); never hosts the help center or replaces the TMS (strictly compiles multi-locale annotated visual assets with TMS-synced callout keys via GitHub PRs or Zendesk/Intercom media APIs); headless Linux Chromium against web staging URLs only (no native mobile/desktop capture).
- **Price:** $499/mo flat ($5,988/yr) for unlimited locales (up to 3,000 localized annotated captures/mo, light+dark, TMS callout-key sync, unlimited seats/PRs) (More for Less)
